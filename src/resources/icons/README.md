# Icon Files

This directory should contain the following icon files:

- `app.ico` - Main application icon (used in taskbar and window title)
- `tray.ico` - System tray icon (normal state)
- `tray-active.ico` - System tray icon (active/window visible state)

## Requirements

- Format: Windows ICO format (.ico)
- Sizes recommended: 16x16, 32x32, 48x48, 64x64, 128x128, 256x256
- Use high DPI (HiDPI) versions for crisp rendering on modern displays

## Placeholder Note

The current files are placeholders. Replace them with actual icon files before building the application.

You can create icons using:
- GIMP (free, open-source)
- Adobe Photoshop
- Online ICO converters
- Visual Studio's built-in icon editor
